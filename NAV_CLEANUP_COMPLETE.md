## 🎨 Design Logic

### Bottom Nav (Primary Actions)
These are the **most frequently accessed** sections:
- **Fixtures** - Check upcoming/live matches
- **Competitions** - Browse tournaments
- **Favourites** - Quick access to followed teams/players
- **Profile** - User account and settings

### Top Nav (Content Discovery)
These are **content-focused** pages:
- **Teams** - Browse all teams
- **Lineups** - View team formations (NEW feature)
- **News** - Read latest articles

### Mobile Menu (Secondary)
Additional pages not in bottom nav:
- **Transfers** - Player transfer news
- Plus all top nav items for consistency

---

## 📱 Mobile User Flow

1. **Primary navigation** → Use bottom nav (thumb-friendly)
2. **Secondary pages** → Use hamburger menu
3. **Quick actions** → Bottom nav always visible

---

## 💻 Desktop User Flow

1. **Primary navigation** → Top nav links
2. **Match browsing** → Homepage (default)
3. **Content discovery** → Top nav categories
